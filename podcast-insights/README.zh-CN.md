# 播客洞察

批准范围：[提案 #158](https://github.com/makecindy/cindy-official-plugins/issues/158#issuecomment-6120456702)。首版包含 M1 导入与原文取证，以及可选的 M2 AssemblyAI 云转写；站内回放留到 M3。

从侧边栏打开资料库，导入 RSS、Apple Podcasts、小宇宙或公开音频链接，再读取与检索已有转录。页面链接导入会创建可见的 Cindy 任务；在任务卡片中选择 RSS 候选、确认云费用。提供8个 `podcast_*` 工具。可选密钥只由 Cindy 保存，Agent 参数不能提交付费转写。

构建：`node podcast-insights/build.mjs`。测试：`node --test .tests/podcast-insights.test.mjs`。最低要求正式稳定版 / Beta Cindy0.1.103。清单资源覆盖中英日韩；页面和运行时支持中英文，其余回退英文。

SQLite 迁移保留旧版0.1.x JSON、回执、结论与导出原文件，使用稳定 ID 导入原转录版本和未完成云任务。删除只影响新索引并创建备份，旧文件和导出仍保留；卸载保留资料库。

与批准草稿的差异：保留原 `assemblyai_key` 名称，因为宿主没有可用于迁移明文密钥的合法接口，避免要求用户重新配置。密钥末尾仅在宿主状态返回 tail 时显示，不读取完整密钥。页面导入和云预估创建普通可见任务（`agent.tasks`），没有后台 Agent 权限。不确定提交仅核对服务商最近100条任务，遇到歧义保持未知。移除普通 DOCTYPE，拒绝实体声明，防止实体展开。

内容授权、API 权限与用户确认分别判断。公开上线前仍需核对服务商保留 / 训练设置及实际模型数据流；本地资料库不代表分析全程本地。实机验证完成前不勾选验收项。

0.2.1修复：迁移中断后恢复、切换单集清空旧正文与定位、长段文本分割且不编造内部时间、保留带时间段落边界、段落与字符游标配对翻页、GUID去重、ISO日期排序、云失败保留已有转录就绪状态、Host错误正确返回失败，以及工具结果明确标注不可信内容。未知云任务匹配限定提交时间窗。来源网络依赖Host严格在途callId、URL／SSRF／DNS／重定向守门与固定连接地址；插件不授予内网访问。费用卡明确仅发送音频URL及处理选项，未请求零保留或退出训练。
